🚌 Bus Booking System – Flask Web Application
🚀 Overview

A full-stack Bus Ticket Booking System built using
Python (Flask), HTML, CSS (Bootstrap), JavaScript & SQLite.

Users can search available buses across multiple routes, book tickets, view fare details, choose payment methods, and receive a confirmation.

✨ Key Features

✔️ Search buses across 20+ routes
✔️ Fare sorting (Low → High)
✔️ Seat availability tracking
✔️ Passenger booking confirmation
✔️ Payment simulation (UPI / Card / Net Banking)
✔️ Dynamic Background Image on every reload
✔️ Clean responsive UI (Bootstrap)
✔️ Form validation using JavaScript
✔️ SQLite database for data storage
